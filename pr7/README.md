## Задача 1
**Файл:** `task1.c`

### Реалізація
- Використано `popen("rwho", "r")` для читання виводу `rwho`.
- Використано `popen("more", "w")` для подачі цього виводу в `more`.
- Передача зроблена через буфер (`fgets` + `fputs`).

```bash

./task1
```

### Технічні особливості
- Обробляються помилки `popen`, читання/запису і `pclose`.
- Якщо `rwho` відсутня в системі, shell повідомить про це.

## Задача 11
**Файл:** `task11.c`

### Реалізація
- Змодельовано просту файлову систему в одному бінарному файлі-образі.
- Підтримуються операції:
  - `init` — ініціалізація образу
  - `create` — додати файл в образ
  - `read` — витягнути файл з образу
  - `delete` — видалити запис файлу
  - `list` — показати вміст

### Запуск
```bash
cc -Wall -Wextra -pedantic -std=c11 task11.c -o task11
./task11 <image> init
./task11 <image> create <host_file> [vfs_name]
./task11 <image> list
./task11 <image> read <vfs_name> <output_file>
./task11 <image> delete <vfs_name>
```

### Технічні особливості
- Формат:
  - заголовок (`magic`, `max_files`, `data_offset`)
  - фіксована таблиця індексу (`VFS_MAX_FILES` записів)
  - область даних
- Видалення логічне: запис в індексі очищається, але дані у кінці файлу не ущільнюються.
- Максимум файлів у цій версії: `128`.
