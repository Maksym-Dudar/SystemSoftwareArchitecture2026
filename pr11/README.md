# Crash Handler 

## Опис завдання

Реалізувати сигналобезпечний (`async-signal-safe`) обробник аварійних сигналів у C, який:

- перехоплює критичні сигнали процесу
- виконує аварійне очищення ресурсів
- виводить діагностичну інформацію
- коректно завершує роботу програми

Програма обробляє:
- `SIGSEGV`
- `SIGABRT`
- `SIGBUS`
- `SIGFPE`
- `SIGILL`

---

## Реалізація

У програмі реалізовано:

- встановлення signal handler через `sigaction`
- сигналобезпечний вивід через `write`
- реєстрація відкритих файлових дескрипторів
- видалення тимчасових файлів через `unlink`
- аварійне завершення через `_exit`
- симуляція помилки доступу до памʼяті (`SIGSEGV`)

При виникненні помилки handler:
1. перехоплює сигнал
2. виконує cleanup ресурсів
3. виводить повідомлення про аварію
4. завершує процес

---

## Технічні особливості

### Async-signal-safe функції

У handler використовуються лише безпечні для signal context функції:

- `write`
- `close`
- `unlink`
- `_exit`

### Обмеження signal handler

У signal handler НЕ використовуються:
- `printf`
- `malloc/free`
- `fclose`
- `pthread mutex`
- інші небезпечні функції стандартної бібліотеки

### Причина crash

Програма навмисно викликає:

```c
volatile int *p = NULL;
*p = 1;
```

для генерації `SIGSEGV`.

## Як запустити

### Компіляція

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 task7.c -o task7
```

### Запуск

```bash
./task7
```
