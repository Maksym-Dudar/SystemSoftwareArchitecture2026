## Мета
Реалізувати програму на C, яка активно використовує:
- динамічну пам'ять (`heap`),
- багатопоточність (`pthread`),
- відображення пам'яті (`mmap`),

і після цього аналізує власний адресний простір через `/proc/self/maps`.

## Реалізація
Файл програми: `maps_demo.c`.

Що робить програма:
1. У головному потоці виділяє пам'ять у купі:
- `malloc(256 KiB)`
- `calloc(24 MiB)`

2. Створює тимчасовий файл у `/tmp`, змінює його розмір (`ftruncate`) і виконує файловий `mmap` (`MAP_SHARED`).

3. Запускає `3` потоки (`pthread_create`).
- Кожен потік виділяє блок у `heap` (`2 MiB`),
- створює анонімне відображення (`mmap`, `MAP_PRIVATE | MAP_ANONYMOUS`) розміром `4 MiB`,
- записує дані у виділені сторінки, щоб пам'ять реально була задіяна.

4. Після завершення потоків відкриває `/proc/self/maps`,
- виводить цікаві регіони (`[heap]`, `[stack]`, `[vdso]`, `[vvar]`, `[vsyscall]`, а також region тимчасового mmap-файлу),
- рахує статистику: кількість регіонів, сумарний віртуальний розмір, кількість `anonymous`/`file-backed` сегментів, кількість `rw-p`, executable сегментів тощо.

5. Виконує коректне звільнення ресурсів (`munmap`, `close`, `unlink`, `free`, `pthread_join`).

### Компіляція
```bash
gcc -O2 -Wall -Wextra -pedantic -pthread task1.c -o task1
```

### 3) Запуск
```bash
./task
```
